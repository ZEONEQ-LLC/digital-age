# Schriften fuer Teilen-Bilder (next/og)

`next/og` (Satori) liest kein WOFF2 und keine variablen Schriften. Darum liegen
hier statische TTF-Schnitte derselben Site-Schriften, nur fuer die serverseitig
erzeugten Bilder (`src/app/showcase/[slug]/teilen-bild/route.tsx`):

- `SpaceGrotesk-Bold.ttf` (700)
- `Inter-Regular.ttf` (400), `Inter-SemiBold.ttf` (600)

Quelle: Google Fonts. Lizenz: SIL Open Font License 1.1, Lizenztexte unter
`src/app/fonts/OFL-SpaceGrotesk.txt` und `src/app/fonts/OFL-Inter.txt`.
